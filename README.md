# Personal Portfolio Website

A modern and responsive portfolio website showcasing my skills, projects, and frontend development journey.

## 🚀 About

This portfolio highlights my work as an aspiring Frontend Developer and Information Technology student. It features interactive animations, responsive layouts, modern UI design, and detailed project showcases.

## ✨ Features

* Modern and responsive design
* Interactive animations and hover effects
* Glassmorphism UI elements
* Custom cursor glow effects
* Mobile-friendly navigation
* Project showcase pages
* Contact section with direct links
* Smooth scrolling and transitions

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript
* Font Awesome
